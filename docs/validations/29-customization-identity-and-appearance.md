# Validation 29 — Customization, identity, and appearance

**Status:** APPROVED



## Decisions and contracts

- Visual Identity System for characters, environments, objects, and other elements.
- Distinguish canonical visual identity, current visual state, and generated image.
- Characters have physical/anatomical traits, face, hair, eyes, skin, clothing, accessories, marks, expression, and body language.
- Appearance changes with time, injury, aging, transformation, equipment, and environment.
- Important environments/objects may also have persistent visual references.
- Worlds define visual direction: style, palette, lighting, references, realism, and cultural conventions.
- Generation is contextual and selective; images do not replace canonical data.


## Implementation rule
Implementations must preserve these decisions and their cross-system contracts. Technical difficulties must be recorded as conflicts/proposals, never resolved through silent relaxation.
