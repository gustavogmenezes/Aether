# Glossary

| Term | Definition |
|---|---|
| World State | Objective state of the world, including hidden facts |
| Character Knowledge | A character’s knowledge, beliefs, and interpretations |
| Player Knowledge | Persistent information actually presented to and discovered by the player |
| Narrative State | Persistent scene continuity and presentation context, not world truth |
| Event Ledger | Authoritative record of events that actually occurred |
| Event Scheduler | Planned future events that have not yet occurred |
| World Calendar | Queryable temporal index over the Event Ledger |
| Timeline | Historical/causal sequence |
| Branch | Branch derived at a divergence point |
| Checkpoint | State snapshot for restoration/branching |
| Diegetic | Element that exists within the fictional world |
| Extradiegetic | Presentation element outside the diegetic reality |
| Narrative Resolution | Level of detail applied to world elements |
| Canonical Content | Approved authored content defining the world’s reality |
| Derived Context | Rebuildable indexes, embeddings, graphs, and summaries |
| Simulation Run | Identifiable execution of a simulation cycle |
| LLM Invocation | Persistent record of one model request and the response actually used or retained |
| Agent Proposal | Structured interpretation associated with an invocation and its validation/application result |
